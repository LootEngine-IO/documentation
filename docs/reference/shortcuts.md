# Keyboard shortcuts

## Anywhere in the editor

| Shortcut | What it does |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save every changed file |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> or <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Jump to the search box |

Undo and redo don’t apply while you’re typing in a text box, so <kbd>Ctrl</kbd>+<kbd>Z</kbd> there undoes your typing instead.

## In the card grid

| Shortcut | What it does |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | Move the selection between items |
| <kbd>Esc</kbd> | Clear the selection |

## In the search box

| Shortcut | What it does |
| --- | --- |
| <kbd>Esc</kbd> | Clear the search |

## In a number field

| Shortcut | What it does |
| --- | --- |
| <kbd>Enter</kbd> | Apply the value |
| <kbd>Esc</kbd> | Put back the value you started with |
| <kbd>↑</kbd> or <kbd>↓</kbd> | Up or down by 1 |
| <kbd>Shift</kbd>+<kbd>↑</kbd> or <kbd>Shift</kbd>+<kbd>↓</kbd> | Up or down by 10 |

Clicking elsewhere also applies the value.

## When adding a usage, value or tag

| Shortcut | What it does |
| --- | --- |
| <kbd>Enter</kbd> | Add the first name that matches what you typed |
| <kbd>Esc</kbd> | Close the list |
