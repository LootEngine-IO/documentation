# Support

Stuck, found a bug or have an idea? Here’s how to reach us.

## Discord

The quickest way to get help is the [LootEngine Discord](https://discord.gg/N2tYjZuNNV). Ask questions, report bugs, suggest features and see what’s coming next. Other server owners are there too, and many have hit the same loot puzzle before.

## Email

For anything you’d rather not post in public, email [hello@lootengine.io](mailto:hello@lootengine.io).

If you think you’ve found a security problem in LootEngine, please email us rather than posting it in the Discord.

## Reporting a bug

A good bug report helps us fix things quickly. Please include:

- **Your LootEngine version.** It’s in **Settings**, next to the **Updates** heading.
- **Windows or Linux**, and which version.
- **What you did**, step by step, and **what happened** compared with what you expected.
- **The exact message** LootEngine showed, if there was one. Messages in the bottom corner disappear after a few seconds, so a screenshot is the easiest way to keep one.
- **The mission and mods**: which map, and which mods are ticked in **Settings**.
- **The file**, if it’s about how a file was read or saved. A copy of the types file, or just the `<type>` entry involved, makes the problem much easier to find. Remove anything private first.

If saving went wrong, the files in `.loot-editor-backups` show what the file looked like before. See [Restoring from a backup](../guide/backups).
